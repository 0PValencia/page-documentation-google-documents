# citation-lab-mcp

Crossref → referencias APA 7.

- npm: [`@0pvalencia/citation-lab-mcp`](https://www.npmjs.com/package/@0pvalencia/citation-lab-mcp)
- GitHub: [0PValencia/citation-lab-mcp](https://github.com/0PValencia/citation-lab-mcp)

```bash
npx -y @0pvalencia/citation-lab-mcp
```

## Tools

| Tool | Uso |
| --- | --- |
| `search_works` | Búsqueda libre en Crossref |
| `format_doi_apa7` | DOI → cadena APA 7 |

## Flujo con Docs

```text
search_works / format_doi_apa7 → append_bibliography / insert_citation
```

No inventes bibliografía: usa resultados reales de Crossref.

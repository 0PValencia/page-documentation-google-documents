# chart-from-data-mcp

Gráficos bar/line/pie/doughnut → PNG vía [QuickChart](https://quickchart.io).

- npm: [`@0pvalencia/chart-from-data-mcp`](https://www.npmjs.com/package/@0pvalencia/chart-from-data-mcp)
- GitHub: [0PValencia/chart-from-data-mcp](https://github.com/0PValencia/chart-from-data-mcp)

```bash
npx -y @0pvalencia/chart-from-data-mcp
```

## Tools

| Tool | Uso |
| --- | --- |
| `render_chart` | `{ type, labels, values, title? }` → path PNG |

## Flujo con Docs

```text
render_chart → insert_image (URI/path rehosteado si hace falta)
```
